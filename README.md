# Manish Adhikari - Portfolio (React)

## Run on your computer
```
npm install
npm run dev
```
Then open the link shown in the terminal (usually http://localhost:5173).

## Build for hosting
```
npm run build
```
Upload the `dist` folder to Netlify, Vercel or GitHub Pages.

## Edit content
All text (projects, skills, education, contact) is in `src/data.js`.
